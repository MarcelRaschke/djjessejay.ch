# 🌆 HOTZE CITY — 3D Open World im "Aufschwung Ost"-Stil

Browser-Game zu Ehren von DJ Jesse Jay (Zürich). Kein Build, keine Abhängigkeiten —
`index.html` öffnen und losspielen.

## Features
- GTA-artige Stadt: Autos, Verkehr, Fahndung (friedlich — Bullen schubsen nur)
- Story-Aufträge: Platten suchen → Kumpels treffen → Chillen → Radiosendung planen
  und austragen → Anlage organisieren → Party in der Disco
- Prozedurale Musik-Engine (WebAudio): OST-TECHNO 106,7 · WILD-LIFE-HOUSE 98,2 · HOTZE-FUNK 89,9
- Musikstudio: eigener Track mit 16-Step-Sequencer und Genre-Router produzieren (Station 4)
- JESSE JAY FM (Station 5): Jesse Jays SoundCloud — und donnerstags 24–06 Uhr
  (Blue Dimension) der echte Radio-LoRa-97,5-Livestream
- Blue Dimension Weekly Special: Stadt schaltet Donnerstagnacht in den Psy-Blau-Modus
- DJJJCOIN: Börse mit Live-Chart, Pump/Crash-Events, Mining-Rig
- AST NFT-Verträge: minten, HODL (Wert steigt), in DJJJCOIN verkaufen
- Eigene Projekte & dynamische Aufgaben
- KI-Anbieter-Modell: der Autopilot-Agent zahlt pro Aktion Inferenz-Tokens,
  Pakete werden beim Anbieter gebucht (MICRO/STANDARD/PRO)
- `window.HotzeAPI`: vollständige API für externe KI-Spieler
- Touch-Steuerung (Joystick + Buttons) für Mobile

## Steuerung
WASD laufen/fahren · Shift sprinten · F ein/aus Auto · R Radio · E interagieren
N NFT-Tower · P Projekte · T KI-Agent · J KI-Token-Pakete · Space Handbremse
